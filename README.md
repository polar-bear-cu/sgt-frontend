# Subglutee Project - Frontend

๊๊UI ของระบบ subscription tracker

### Prerequisite

- Node 22
- `npm`

### Setup

```terminal
git clone https://github.com/polar-bear-cu/sgt-frontend.git
cd sgt-frontend
npm install
cp .env.example .env
npm run dev
```

เปิด http://localhost:5173

### Useful Commands

```terminal
npm run dev            dev server (port 5173)
npm run build          typecheck + production build
npm run lint           eslint
npm run format         prettier --write
npm run format:check   prettier --check
```
